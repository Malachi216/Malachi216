## 👋 About Me

I am an AI and data professional focused on building end-to-end machine learning, RAG, analytics, and decision-support systems.

My work spans applied machine learning, NLP, trustworthy AI, model evaluation, explainability, and deployable software. I am especially interested in systems that move beyond notebooks into usable products, dashboards, APIs, and real-world workflows.

I also conduct applied AI research in emergency and healthcare decision support, with work on calibrated risk prediction, uncertainty-aware prioritization, and multimodal triage systems.

## 🚀 Featured Projects

### 🚑 EmergencyAI
**Machine Learning • XGBoost • Calibration • SHAP • Decision Support**

An AI-powered emergency decision-support project focused on risk prediction, model calibration, uncertainty, explainability, and resource-prioritization workflows.

Built to demonstrate how machine learning can support high-stakes operational decisions while keeping uncertainty and human oversight visible.

➡️ GitHub: https://github.com/Malachi216

### 💼 JobReady 2.0
**AI-Assisted Job Intelligence • APIs • Web Application • Deployment**

A deployment-focused AI application for job analysis and career support, developed as a production-style reference project with a functional web interface and backend logic.

The project emphasizes practical application architecture, deployment, UI/API integration, and iterative product development.

➡️ GitHub: https://github.com/Malachi216/jobready_reference_project

---

### 🔎 RAG Web Research Agent
**LangChain • ChromaDB • Streamlit • Ollama**

A retrieval-augmented research assistant that combines web search, cited summaries, vector-based retrieval, and persistent memory.

Designed to explore practical RAG architecture, retrieval workflows, citation-aware responses, and local LLM integration.

➡️ GitHub: https://github.com/Malachi216/rag-web-research-agent

---

### 🏥 Multimodal AI Triage
**Healthcare AI • NLP • Machine Learning • Calibration • Explainability**

Research-driven emergency department triage pipeline for predicting ICU admission within 24 hours using structured clinical features and text-based information.

Includes model comparison, calibration, uncertainty analysis, and explainability methods for safer clinical decision support.

➡️ GitHub: https://github.com/Malachi216/ed-triage-icu24h
